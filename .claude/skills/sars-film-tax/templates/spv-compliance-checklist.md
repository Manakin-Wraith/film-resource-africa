This checklist is a working document. It is a draft for discussion with a registered SARS tax practitioner; it is not tax advice.

## A. Incorporation & registrations

- [ ] Pty (Ltd) incorporated at CIPC; MOI reviewed for waterfall / reserved-matter clauses
- [ ] SARS Income Tax reference issued and confirmed (do not rely on auto-registration)
- [ ] VAT registration filed (voluntary if below R1m forecast; compulsory once threshold met) — see `references/vat-film-production.md`
- [ ] Category C (monthly) VAT requested if SPV expects a persistent refund position
- [ ] PAYE / SDL / UIF registered before first crew payment
- [ ] COIDA registration filed
- [ ] CIPC beneficial-ownership filing lodged
- [ ] SPV bank account opened in SPV's own name; **all** production funds flow through this account

## B. Documentation foundations (build from day one)

- [ ] Shareholders' agreement and waterfall schedule
- [ ] Chain-of-title file (option, writer, director, talent, music)
- [ ] Production services agreement with foreign principal (if applicable) — explicit non-SA address for principal; tax invoice template marked "Zero-rated — s11(2)(l)" if facts support
- [ ] Tax Residency Certificates collected for every non-resident counterparty
- [ ] Inter-company licence / service agreement (if HoldCo structure) drafted with arm's-length pricing memo

## C. Ongoing compliance calendar

- [ ] VAT201 returns scheduled (bi-monthly Cat A/B; monthly Cat C)
- [ ] EMP201 monthly by the 7th
- [ ] EMP501 interim (October) and final (May) reconciliations
- [ ] Provisional tax IRP6: first by 6-month mark, second by year-end, third top-up within 6/7 months after year-end
- [ ] Withholding tax returns scheduled for any s47, s49, s50 outflows
- [ ] ITR14 within 12 months of year-end

## D. Tax-sensitive operating disciplines

- [ ] Every per diem / subsistence payment cross-checked against the SARS published rate table
- [ ] Every freelancer engagement assessed against the Fourth Schedule independent-trader tests; outcome documented per role
- [ ] Every cross-border payment screened for WHT (s47/s49/s50) and DTA position before payment
- [ ] Entertainment input VAT denials applied (no input VAT on entertainment expenses except qualifying on-set catering)
- [ ] Documentary file for any zero-rated invoice held per BGR 11 (contract, payment proof, address evidence)

## E. Red flags to escalate to a practitioner immediately

- [ ] Any payment that may create a foreign PE for a co-producer
- [ ] Any offshore IP step (assignment, licence, emigration)
- [ ] Any shareholder loan, sweetheart interest rate, or value shift to/from a connected party
- [ ] Any restructure within 18 months of an exploitation event
- [ ] Any arrangement matching the reportable-arrangements list (s35 TAA)
